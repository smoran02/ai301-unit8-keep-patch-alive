# Keep Patch Alive

A team game for CodePath AI301, unit 8.

Your room just opened a pull request on playlistr, a made-up Python library, and the PR comes with a pixel pet. Monty, your PR-monitor, reads everything that lands on the thread and drafts a move. Your room decides what actually gets sent.

- **Four weeks, four levels.** Each level is one week in your PR's life.
- **Three hearts a week.** A wrong call costs one. Run out and your pet walks out; win it back and pick up at the first call you got wrong.
- **After week 4:** pet-sitting (four bonus cases), the Nitpick Storm (just for fun), and a photo booth.

One person shares the page in your breakout room and clicks for everyone. Anyone who wants their own copy can open the game too and type the same room number.

TFs: add `?demo` to the link (`index.html?demo`) for a short made-up demo level. It never touches a real game.
